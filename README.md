# Weav

AI-powered workflow automation and process monitoring platform.

## Repository structure

- `apps/` — user-facing Web and Mobile applications
- `services/` — backend microservices
- `packages/` — shared contracts, workflow schemas, and minimal shared utilities
- `infrastructure/` — Docker, Nginx, RabbitMQ, Redis, database bootstrap, monitoring
- `docs/` — architecture and technical documentation
- `tests/` — cross-service integration and end-to-end tests
- `examples/` — sample workflows
- `scripts/` — development/build/test/database scripts

See `docs/architecture/repository-structure.md` for the planned repository layout.
