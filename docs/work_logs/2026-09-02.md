## 7. Thay đổi đã thực hiện

### 7.1. Code và hành vi

- **Workspace Service:** thêm persistence model cho workspace, membership, connection và credential; chưa thêm business use case hoặc public CRUD flow.
- **Workflow Service:** thêm persistence model cho workflow/version/trigger, execution tree, retry attempt, execution log, file metadata, transactional outbox và agent run/step; chưa thêm execution runtime.
- **Shared foundation của mỗi service:** thêm exception hierarchy, API error envelope, global handler và request validation mẫu.

### 7.2. Dữ liệu, schema và migration

- **Database/schema:** Workspace dùng schema `workspace`; Workflow dùng schema `workflow` trên database/service tương ứng.
- **Migration:** Workspace `V1__create_workspace_entities.sql`; Workflow `V1__create_workflow_entities.sql`.
- **Dữ liệu seed/test:** test dùng dữ liệu test/integration cần thiết; không ghi secret hoặc dữ liệu production vào log.
- **Tính tương thích:** migration V1 là baseline hiện tại; refactor không được đổi tên bảng/cột/enum persistence nếu chưa có migration và quyết định tương thích riêng.

### 7.3. Cấu hình, hạ tầng và dependency

- **Database properties:** giữ cấu hình theo service và dùng pooled Neon endpoint với SSL required trong môi trường development/shared.
- **Timezone:** cấu hình Hibernate/JDBC theo UTC.
- **Security properties:** có `weav.jwt.*` qua `JwtProperties`, nhưng chưa có issuer, decoder/filter hoặc token lifecycle.
- **Hạ tầng:** có actuator/health foundation và cấu hình service trong Compose; chưa thêm runtime messaging/cache/storage integration.

### 7.4. API, bảo mật và quan sát hệ thống

- **Route/contract:** chỉ có request validation foundation (`CreateWorkspaceRequest`, `CreateWorkflowRequest`); chưa có business API hoàn chỉnh.
- **Security:** route health/health-related endpoint được permit; route còn lại protected theo stateless security skeleton; chưa phải JWT authentication hoàn chỉnh.
- **Validation/error response:** dùng envelope `ApiErrorResponse` với mã lỗi, message, details, timestamp, status và path; global handler xử lý domain/validation/web errors.
- **Health/metrics/logging:** actuator health configuration đã được chuẩn bị; cần runtime recheck sau mỗi lần refactor.
