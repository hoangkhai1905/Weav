## Adaptive OCR accuracy session

- **Decision:** keep the existing pretrained PaddleOCR weights; improve the inference pipeline with one bounded fallback pass instead of fine-tuning from the current small corpus.
- **Implementation:** the default OpenCV preprocessing remains unchanged. A fallback may apply bounded upscale/contrast enhancement and preserves an inverse coordinate transform. PaddleOCR now selects the better of the default and fallback result using a deterministic quality score. Fallback is limited to one extra pass per page and is triggered by empty/very short output or low average page confidence.
- **Benchmark reporting:** the real corpus now prints per-fixture CER/WER, character/word counts, and block counts.
