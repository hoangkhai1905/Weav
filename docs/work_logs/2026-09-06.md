## 4. Phát hiện chính

### Identity API hiện có

- `POST /auth/register` → `201`
- `POST /auth/login` → `200`, token pair
- `POST /auth/refresh` → `200`, token pair mới
- `POST /auth/logout` → `204`
- `GET /users/me` → `200`, yêu cầu access JWT

Các route trên là Identity-local. Gateway chưa có mapping công khai `/api/...`.

### Mismatch cần lưu ý cho frontend

Mobile HTTP auth đang gọi `/api/auth/login`, `/api/auth/register`, `/api/auth/refresh`, `/api/auth/logout`, `/api/auth/me`. Identity contract hiện định nghĩa `/auth/*` và `/users/me`. Cần chốt Gateway mapping hoặc sửa HTTP adapter trong task integration riêng; không tự suy đoán contract.

Web chưa có HTTP repository/factory tương ứng và vẫn dùng `localStorage` mock theo frontend rule.
